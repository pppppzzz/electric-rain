# 实测日志待补录

打包时未检测到Arduino串口，尚无真实的“校准→吹气选歌→演奏→结束”日志。本目录不包含模拟日志。

连接UNO，关闭IDE串口监视器以及其他占用串口的软件。在本包目录打开PowerShell，执行（COM3替换成实际端口）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\capture_serial.ps1 -Port COM3
```

脚本以115200/8N1读取，打开DTR可能复位UNO，不写入任何串口命令、不上传程序。没有看到校准提示时，按一次板上RESET。校准时安静，中央闪烁后吹气并完成一整首歌。录制会保留全部收到的原始串口文字，直至本轮结束后再次出现等待吹气提示，最多180秒。

raw.txt 不混入电脑提示、模拟输入或时间戳；配套 capture.json 记录录制起止时间、串口、SHA256、是否完成全流程。异常或超时会保留部分数据并标记不完整，不能把它当完整日志交付。

注意：录制到同一个v3.2横幅不能证明具体选曲门限一致，仍需核对最后上传来源。若板内不是当前源码，请保留实际工程版本，勿为了凑日志改程序。
