# 现有项目接线清单

以下按当前 Config.h 和本聊天约定整理。此前图片能确认模块种类，但无法逐根确认当前端点，因此是程序要求的接线，尚未独立实物复核；不能把未核实的线序标为已实测。

| 模块 | 模块端子 | UNO R3 |
|---|---|---|
| 声音模块 | AO | A0 |
| 声音模块 | VCC / GND | 5V / GND |
| 声音模块 | DO | 不接 |
| HC-SR04 | Trig / Echo | D6 / D7 |
| HC-SR04 | VCC / GND | 5V / GND |
| MAX7219 四联点阵 IN端 | DIN / CLK / CS或LOAD | D11 / D13 / D10 |
| 点阵 | VCC / GND | 稳定5V / 共地 |
| 交通灯 | R / Y / G | D3 / D4 / D5 |
| 交通灯 | GND | GND |

交通灯假定为自带限流电阻、HIGH点亮的 GND/R/Y/G 模块；G是绿灯，不是地。若有额外VCC且模块支持5V则接5V。蜂鸣器已拆除，D9不使用。D0/D1不接模块，USB负责电脑串口。所有模块共地；独立电源供点阵时避免与USB 5V直接并联。当前具体电源接法未核实。

点阵映射：REVERSE_MODULES=false、TRANSPOSE_TILE=false、FLIP_TILE_X=false、FLIP_TILE_Y=true；SPI=250000Hz，亮度=1。距离总范围30–149mm、每键15mm、内部边界防抖3mm。
