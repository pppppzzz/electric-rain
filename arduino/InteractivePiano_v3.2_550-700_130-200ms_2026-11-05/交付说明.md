## 依赖及构建

- 目标：Arduino UNO R3，ATmega328P，16 MHz，FQBN arduino:avr:uno。
- 本机 Arduino AVR Boards core：1.8.8。
- 本机 AVR GCC：7.3.0-atmel3.6.1-arduino7。
- Arduino.h 与 SPI.h：Arduino AVR core 自带；avr/pgmspace.h：AVR 工具链自带。
- 不需要 LedControl、MD_MAX72XX、NewPing、第三方声音库等库。
- Arduino IDE 的精确版本及最后一次上传所用工具链版本未核实。IDE 打开 InteractivePiano/InteractivePiano.ino 即可。
- verify-build.ps1 是 Windows PowerShell 本地验证脚本，要求本机已安装上述 AVR core/编译器；只编译，不上传。
- 此前对该源码的本地验证：Flash 9484 字节，静态 SRAM 425 字节；不代表已验证板内二进制相同。

SHA256SUMS.txt 校验包内文件完整性；manifest.json 保存原始工程文件哈希。两者都不是板内固件读回证明。
