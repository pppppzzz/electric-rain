# 课程要求对照（以实机验收为准）

| 要求 | 当前实现与证据 |
|---|---|
| Arduino 基础电路 | 用户给出 UNO R3 接线计划；实际电路需组员演示 |
| 两种传感器 | HW-484 声音、HC-SR04 超声波，类型不同；待最新固件与实物验证 |
| 两种实体输出 | MAX7219 点阵与交通灯是两个模块，但都属 LED，需向老师确认是否认可为不同输出类型 |
| Arduino 与网页联动 | 网页串口接收、触发音频、动画、显示分数已实现；真实 COM 连接和数据仍待现场验证 |
| 双向控制 | 有可配置 start 写入接口，现有历史固件不接收，尚未完成真实双向控制 |
| 现场携带 Arduino | 下次课携带 UNO、全部传感器、输出、USB 数据线与电脑，提前彩排 |
| 约五分钟汇报 | 已提供 presentation-outline.md，无 PPT 文件 |

不能将模拟模式通过等同于硬件通过，也不能直接声称已完全符合课程全部要求。若老师不认可两种 LED 模块为不同类型输出，由小组与老师确认补充方案，本次不擅自改硬件。
