# 五分钟汇报提纲

- 0:00–0:40 创意：Electric Rain，把输入声音变成选曲，把手与空间的距离变成钢琴和雨水，雨夜记事本记录短暂的参与。
- 0:40–1:30 装置：展示 UNO、声音传感器、超声波、8×32 点阵与交通灯；说明两个输入模块和两个实体输出模块。
- 1:30–2:15 交互：声音强弱决定三首曲目之一；点阵出谱，距离检测实际音区；Arduino 判定并计算成绩。
- 2:15–3:00 网页：独立程序绘制的复古窗口、旋转 CD、音符雨与水面；按实际弹出的音高播放，即使弹错也照实发声，网页不算分。
- 3:00–4:30 实机演示：Chrome/Edge Connect → 发声选歌 → 演奏 → 故意一次错误和一次漏音 → 实际结束结算。备用模拟演示必须先说明是测试数据。
- 4:30–5:00 技术与边界：换行 JSON、低延迟 Web Audio、状态同步；如双向开始指令未完成必须说明。总结作品如何把物理动作留下可见且短暂的雨水痕迹。
