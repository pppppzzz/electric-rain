# 曲目元数据

1. Jasmine Flower（茉莉花）
2. Jingle Bells（铃儿响叮当）
3. Doll and Bear Dance（洋娃娃和小熊跳舞）

满分按同学交付版 Songs.h 中的有效音符（数字 1–8）数量 ×3，空格休止不计：茉莉花 40 音，满分 120；铃儿响叮当 44 音，满分 132；洋娃娃和小熊跳舞 70 音，满分 210。演奏计分处显示满分；结算进度为当前分数/满分，并显示还差多少分。此进度仅表示得分完成度，不是歌曲播放进度，不参与判定或改分。

编号固定 1~3，新 HTML 使用 web/native/data.js。旋律、节奏、谱面、时间窗与判分完全由 Arduino 负责。网页没有伴奏、曲谱播放器或自动演奏。C4、D4、E4、F4、G4、A4、B4、C5 分别映射 actual 1~8。

音色为本地 Web Audio 加法合成：六个衰减正弦泛音和低通音板近似，并非录制钢琴采样。无外部音频版权依赖；后续可替换为合法本地采样。原根目录 songs.md 和 generate_songs.py 保留为历史固件资料。
