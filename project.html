代码与版本

Arduino 负责传感器、点阵和灯光判定；网页负责实际钢琴声音、雨水视觉，以及按真实判定累计成绩。

Arduino 工程需同时保留 .ino、Config.h、Songs.h 和 GameRules.h。打开 .ino 时使用同目录的全部文件，不能只复制主程序。接线与旧 ElectricRain 历史工程不同，请以此页和当前 Config.h 为准。

原始 Arduino 快照已保留，板内版本与实物接线仍需操作者自行核对。现有固件自动倒计时开始；r 是重新校准，不是开始命令。

网页连接

  1. 使用数据 USB 线连接 UNO，关闭 IDE 串口监视器和绘图器。
  2. 用 Windows Chrome/Edge 打开雨夜记事本，点击连接设备，选择 UNO 对应 COM；波特率为 115200。
  3. 必要时按一下板上的 RESET。安静两秒，再吹气选歌；输入峰值 550–700 有效。
